# Kamenictví Adámek

- Zachovat statické HTML/CSS, bez sestavování frontendu. Tiskové návrhy `loga.html`, `plakat.html`, `vizitka.html` neměnit.
- Produkt a ověřené kontakty: `PRODUCT.md`. Nevymýšlet ceny ani termín odpovědi.
- Konfigurátor: zachovat všechny tvary, konstrukce, rytiny a možnosti. Písma nápisů jsou součást návrhu; písma ovládání odpovídají webu.
- Kontrola (2026-10-08): `node --test tests/*.test.mjs`; náhled `node serve.mjs`. Služba pro odesílání je závislost nasazení, úspěch potvrdit až po přijetí e-mailovou službou.
- Ověřit desktop 1440 px a mobil 390 px, sdílení/obnovení návrhu, změnu materiálu, nápis a chybové stavy formuláře.
